    Annex I. Sistema de gestor de paquets per a Linux: APT i SNAP

    Sistema de gestor de paquets APT (Advanced Package Tool)

    APT (Advanced Package Tool) és el gestor de paquets utilitzat en distribucions basades en Debian i Ubuntu.
    Permet instal·lar, actualitzar i eliminar paquets de programari des de repositoris oficials o fonts externes.

    Característiques principals:

    • Utilitza paquets amb extensió .deb.
    • Gestiona automàticament les dependències necessàries per a cada programa.
    • Manté actualitzat el sistema amb ordres simples.
    • És ràpid, lleuger i està integrat amb l’estructura del sistema operatiu.
    • Es gestiona mitjançant la línia d’ordres amb ordres com: 
    sudo apt update        # Actualitza la llista de paquets disponibles
sudo apt upgrade       # Actualitza els paquets instal·lats
sudo apt install nom_paquet   # Instal·la un nou paquet
sudo apt remove nom_paquet    # Elimina un paquet
...

    APT és el sistema més tradicional i fiable per gestionar el programari en entorns Debian i Ubuntu, ideal per a la gestió del sistema base i aplicacions essencials.

    Guia APT

    Disposeu de més informació a l'article https://itsfoss.com/apt-command-guide/

    Sistema de gestor de paquets Snap

    Snap és un sistema de paquets universal desenvolupat per Canonical, la mateixa empresa darrere d’Ubuntu.
    A diferència d’APT, Snap empaqueta totes les dependències necessàries dins del mateix paquet, permetent que el programari funcione igual en qualsevol distribució Linux.

    Característiques principals

    • Utilitza paquets amb extensió .snap.
    • No depèn de les llibreries del sistema; cada aplicació és autosuficient.
    • Les actualitzacions són automàtiques i segures.
    • Cada aplicació s’executa en un entorn aïllat (sandbox) per millorar la seguretat.
    • Compatible amb múltiples distribucions Linux modernes.
    • Es gestiona amb comandes senzilles des de la línia d’ordres: 
    sudo snap install nom_paquet    # Instal·la un paquet Snap
sudo snap remove nom_paquet     # Elimina un paquet Snap
sudo snap refresh               # Actualitza tots els paquets Snap
...

    Guia SNAP

    Disposeu de més informació a l'article https://itsfoss.com/install-snap-linux/
