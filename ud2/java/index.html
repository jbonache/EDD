    Netbeans i Java

    Netbeans i Java

    NetBeans treballa amb projectes per a crear aplicacions amb el llenguatge de programació de Java.
    Per a fer una prova, podríem crear un arxiu simple, però per desenvolupar una aplicació és millor crear un projecte.

    Per fer-ho:

    1. Al menú superior, seleccioneu File → New Project.
    2. Seleccioneu el llenguatge amb el qual voleu desenvolupar el projecte i el tipus d’aplicació (en aquest cas el framework de Maven).

    Al projecte li hem de donar un nom. Per defecte se guardarà en la carpeta NetBeansProjects que s’haurà crear al nostre home o a Mis Documentos.

    Donar nom al projecte

    Poseu un nom al projecte.
    Per defecte, el projecte es guardarà a la carpeta NetBeansProjects dins del vostre directori personal.

    A la part esquerra de la pantalla de NetBeans, apareixerà la llista de projectes creats.
    Podem veure que el projecte que acabem de crear ja es mostra a la llista.

    Crear la classe principal

    Automàticament, NetBeans crearà un arxiu amb el mateix nom i extensió .java.

    Així ja podem començar a treballar. NetBeans genera la classe i el mètode main, i només cal escriure dins del main les instruccions que volem que execute l’aplicació.

    Exemple “Hola, món”

    Ara farem la nostra primera aplicació Java: el clàssic “Hola, món”.
    Només cal copiar les línies següents dins del mètode main:

    public class ProvaJava {
    public static void main(String[] args) {
        System.out.println("Hola, món!");
        System.out.println("Estem fent una aplicació Java amb Netbeans");
    }
}

    Executar l’aplicació

    Per executar l’aplicació correctament, podeu utilitzar Run → Run Project al menú, o bé fer clic al botó d’executar:

    La primera vegada que executeu el projecte, és possible que NetBeans demane quina és la classe principal. Normalment la detecta automàticament i la mostra per defecte.
