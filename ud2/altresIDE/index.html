    IntelliJ IDEA i PyCharm

    IntelliJ IDEA

    IntelliJ IDEA és un entorn de desenvolupament integrat (IDE) desenvolupat per JetBrains, principalment pensat per al llenguatge Java, tot i que també suporta molts altres llenguatges com Kotlin, Groovy, Scala i fins i tot Python mitjançant plugins.

    Característiques principals:

    • Autocompletat intel·ligent i suggeriments de codi.
    • Integració amb sistemes de control de versions com Git i SVN.
    • Debugger potent i eina de testing incorporada.
    • Suport per frameworks populars com Spring, Hibernate, JavaFX, entre d’altres.
    • Refactoring avançat i detecció de possibles errors en temps real.
    • Gestió de projectes modularitzada, amb suport per a Maven i Gradle.

    IntelliJ IDEA és molt utilitzat tant en entorns professionals com acadèmics, especialment en projectes grans i complexos que requereixen un IDE robust i flexible.

    PyCharm

    PyCharm és un IDE creat també per JetBrains, específicament orientat al desenvolupament en Python.

    Característiques principals:

    • Editor intel·ligent de Python amb autocompletat, suggeriments i detecció d’errors.
    • Integració amb entorns virtuals (virtualenv, conda).
    • Debugger visual i eina de testing incorporada.
    • Suport per a desenvolupament web amb frameworks com Django, Flask, FastAPI.
    • Control de versions integrat (Git, SVN, Mercurial).
    • Suport per a bases de dades, SQL i eines de desplegament.
    • Refactoring avançat i anàlisi de codi en temps real.

    PyCharm és ideal per a projectes de Python de qualsevol mida, des de scripts petits fins a aplicacions web completes i projectes de ciència de dades.

    Instal·lació de IntelliJ IDEA Ultimate i PyCharm Professional amb llicència educativa (Ubuntu amb Snap)

    🚀 Guia per a estudiants

    🧭 1. Verifica la teva llicència educativa

    • Inicia sessió al teu compte JetBrains:
      👉 https://account.jetbrains.com
    • Comprova que tens accés a llicències educatives:
      👉 https://www.jetbrains.com/community/education/#students
    • Si tot és correcte, veuràs:

      “You have access to JetBrains Educational Licenses.”

    💻 2. Descarrega els IDEs

    • IntelliJ IDEA Ultimate:
      👉 https://www.jetbrains.com/idea/download/
      Tria el teu sistema operatiu i fes clic a Download a la secció Ultimate.
    • PyCharm Professional:
      👉 https://www.jetbrains.com/pycharm/download/
      Tria el teu sistema operatiu i fes clic a Download a la secció Professional.

    ⚙️ 3. Instal·lació general

    1. Executa els instal·ladors corresponents segons el teu sistema operatiu.
    2. Accepta les opcions per defecte (ubicació, associació de fitxers, etc.).
    3. Obre els IDEs un cop finalitzada la instal·lació.

    🐧 3b. Instal·lació en Linux Ubuntu

    ⚡ Opció 1: Instal·lació amb Snap (més fàcil)

    • IntelliJ IDEA Ultimate: 
      sudo snap install intellij-idea-ultimate --classic
    • PyCharm Professional: 
      sudo snap install pycharm-professional --classic
    • Obre els IDEs des del menú d’aplicacions o amb el comando intellij-idea-ultimate / pycharm-professional.

    🔐 4. Activa la llicència educativa

    1. Selecciona “Activate via JetBrains Account” en cada IDE.
    2. Inicia sessió amb el teu correu educatiu.
    3. L’IDE detectarà automàticament la llicència i activarà la versió Ultimate/Professional.

    ✅ 5. Verifica la instal·lació

    • IntelliJ IDEA Ultimate:
      Ves a Help → About i comprova:
      IntelliJ IDEA 2025.x (Ultimate Edition)
Licensed to: El teu nom (Educational License)
    • PyCharm Professional:
      Ves a Help → About i comprova:
      PyCharm 2025.x (Professional Edition)
Licensed to: El teu nom (Educational License)

    🔄 6. Renovació anual

    • Les llicències educatives duren 1 any.
    • Renovació gratuïta:
      👉 https://www.jetbrains.com/shop/eform/students

    💡 Atenció: La mateixa llicència educativa funciona per a tots els productes JetBrains (IntelliJ, PyCharm, etc.), així que només cal que facis el procés d’activació una vegada per compte.
