    Pràctica de depuració 1: Comptador de vocals

    Aquest programa mostra per pantalla el número de vocals que hi ha en la frase:

    «Hola, estem aprenent debug en classe d'Entorns de Desenvolupament de 1r de DAM o DAW.»
    de la línia 11.

    def comptar_vocals(frase):
    vocals="aeiou"
    comptador=0
    it=0
    for lletra in frase:
        it += 1
        if lletra in vocals:
            comptador += 1
    return comptador

frase = "Hola, estem aprenent debug en classe d'Entorns de Desenvolupament de 1r de DAM o DAW."
numVocals = comptar_vocals(frase)
print(f"Hi ha {numVocals} vocals en la frase.")

    Instruccions

    • Afegeix un punt d’interrupció (breakpoint) en la línia:
    for lletra in frase:

    • Fes el debug amb Step Over i explica què ocorre quan la variable it val 40 i s’executa aquesta iteració del for.

    • Sabries fer el debug amb un breakpoint condicional? Com ho faries?

    • Modifica el programa per a optimitzar el codi i millorar el programa.

    Pràctica de depuració 2: Comptador de paraules

    Aquest programa ha de comptar el número de paraules d’una frase, però conté 2 errors. El teu objectiu és trobar-los fent el debug i solucionar-los.

    def comptar_paraules(oracio):
    paraules = oracio.split(" ")
    comptar = 1
    for paraula in paraules:
        comptar + 1  
    return comptar

# Input de l'usuari
oracio = input("Introdueix una oració: ")
print(f"L'oració té {comptar_paraules(oracio)} paraules.")

    Instruccions

    1. Col·loca un punt d'interrupció (breakpoint) en la línia:
    paraules = oracio.split(" ")

    1. Executa el depurador i utilitza el panell de variables per observar el valor de paraules i comptar en cada iteració del bucle i veure què ocorre.

    2. Troba i corregeix els 2 errors per a què el programa funcione correctament.

    Pràctica de depuració 3: Calculadora de mitjana

    Este programa agafa una llista de números i hauria de calcular la mitjana. No obstant això, té alguns errors que impedeixen que funcione correctament.

    def calcular_mitjana(numeros):
    suma = 0
    for numero in numeros:
        suma += numero
    mitjana = suma / len(numeros)  
    return mitjana

# Input de l'usuari
numeros = input("Introdueix una llista de números separats per comes: ")
numeros = numeros.split(",")  # Converteix a llista de cadenes

if (numeros != ['']):
    numeros = [int(num) for num in numeros]  # Converteix cada element a enter
    print(f"La mitjana de la llista és: {calcular_mitjana(numeros)}")
else:
    print("La llista està buida.")

    Instruccions

    1. Col·loca un punt d'interrupció (breakpoint) en la línia:
    suma += numero

    1. Executa el depurador i observa el valor de suma en cada iteració.

    2. Troba l'error lògic que podria ocórrer si la llista està buida i modifica el codi per solucionar aquest cas correctament.

    Ajuda: una llista està buida si és igual a [' '].

    Pràctica de depuració 4: Repartidor d’Amazon

    Aplica les tècniques de debugging en PyCharm o Visual Studio Code, per a controlar el valor de variables dins d’un bucle que simula el treball d’un repartidor d’Amazon.

    Descripció del programa

    El repartidor treballa durant 30 dies amb les següents característiques:

    1. Repartiment setmanal de paquets:
    2. Dies 1–5: augment del 2% diari sobre els paquets a repartir.

    3. Dies 6–7: descens del 20% diari sobre els paquets a repartir.

    4. Paquets en ruta: el repartidor acumula els paquets a repartir cada dia.

    5. Entregues: cada dia s’entrega el 15% dels paquets en ruta, i a partir del dia 15 el nombre d’entregues es duplica.

    6. Capacitat màxima del repartidor: 760 paquets en ruta.

    Codi base (per depurar)

    capacitat_max = 760
paquets_inicials = 200
paquets_a_repartir = paquets_inicials
paquets_en_ruta = 0

for dia in range(1, 31):
    dia_setmana = ((dia - 1) % 7) + 1

    if dia_setmana <= 5:
        paquets_a_repartir = int(paquets_a_repartir * 1.02)
    else:
        paquets_a_repartir = int(paquets_a_repartir * 0.80)

    paquets_en_ruta += paquets_a_repartir
    paquets_en_ruta = int(paquets_en_ruta)

    entregats = int(paquets_en_ruta * 0.15)
    if dia >= 15:
        entregats *= 2

    paquets_en_ruta -= entregats

    pass

    1. Quin dia es supera la capacitat màxima de paquets en ruta?

    2. Quants paquets entrega el repartidor de més o de menys entre el dia 20 i el 21?

    3. Quants paquets entrega el repartidor el dia 18**?

    4. Quants paquets en ruta de diferència hi ha entre el segon dia i el dia 11?

    5. Quants dies s’entreguen entre 75 i 100 paquets**?
